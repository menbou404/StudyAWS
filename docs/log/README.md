# 学習ログ

1日1ファイル（`YYYY-MM-DD.md`）で、やったこと・学んだこと・ハマったことを記録する。
手順書（どうやるか）は `docs/phaseN-*.md`、ここは日記（何をして何を思ったか）。

## テンプレート

```markdown
# YYYY-MM-DD（Phase N: タイトル）

## やったこと
-

## 学んだこと
-

## ハマったこと・疑問
-

## 次やること
-
```

## 公開リポジトリに書かないもの

- AWS アカウントID、アクセスポータルURL、メールアドレス
- アクセスキー、パスワード、`.pem` などの鍵
- IPアドレスやリソースID（`i-0abc...` など）は伏せ字にする（`i-xxxx`）
